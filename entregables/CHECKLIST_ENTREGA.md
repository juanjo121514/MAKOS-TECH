# Checklist de entrega - MakosTech

Segun las instrucciones del profesor, el entregable debe incluir:

- [x] Perfil breve del cliente.
- [x] Problema a resolver del cliente.
- [x] Diseno del experimento / metodologia de validacion.
- [x] Herramienta usada: encuesta, entrevistas, showroom o testing.
- [x] Resultados visuales de validacion.
- [x] Modelo de ingresos.
- [x] Base de datos de 70 clientes potenciales.
- [x] Base de datos de 20 proveedores.
- [x] Base de datos de 10 competidores.
- [x] Evidencia de 1 venta o venta piloto.
- [x] Presentacion corta para exponer.
- [ ] Fotos reales de focus group, showroom o testing si las tienen.
- [ ] Link de encuesta si la publican en Google Forms.
- [ ] Capturas de pantalla de la aplicacion funcionando.
